# DeepSeek Harness 会话回收站

给 DeepSeek Harness 补上「删除」这一半。

宿主自带**归档**，却没有**删除**：归档的会话从侧边栏消失、随时可以恢复，可它的日志会一直躺在磁盘上。这个插件补上另一半 —— 右键把会话真正删掉，再给一个能反悔、能批量、能自动过期的回收站。

## 它做什么

在左侧工作区**右键一个会话**，选择
**删除会话并移入回收站**。

- 会话通过与内置「归档」完全相同的持久化写入被归档：立刻从侧边栏消失，正在跑的任务被停掉。
- 它的存储目录被移入 `<DSH_HOME>/session-purge/trash/<trashId>/`，同时留下一份 JSON 记录（会话 id、标题、工作目录、原路径、字节数、删除时间）。
- 侧边栏那一行立刻消失，**不需要重启 DSH**。

左栏底部（设置按钮上方）的 **🗑 回收站** 按钮打开回收站面板，列出每个被删的会话及大小和删除时间，提供：

| 操作 | 行为 |
| --- | --- |
| **恢复** | 文件搬回原位，并撤销隐藏它的那次归档写入，会话重新出现在侧边栏。 |
| **彻底删除** | 整个会话目录移交给操作系统自己的废纸篓（macOS 上是 `~/.Trash`），文件管理器里仍可还原。 |
| **清空回收站** | 一次性处理全部条目，需二次点击确认。 |
| **批量** | 勾选若干行（或全选），一次性恢复或删除。 |
| **保留期** | 超过所选期限的条目自动过期，移交系统废纸篓；选「永不」则关闭过期。 |

工作区搜索图标**旁边还有一个刷新按钮**，会重新拉取会话列表，磁盘上发生变化的会话无需重启即可看到。

## 安装

从插件市场安装，或直接从源码安装：

```sh
dsh plugin --profile desktop add z664w4zps8-spec/dsh-session-trash
```

需要 DSH 0.2.2-alpha.3 或更新版本（它依赖的共享右键菜单服务从该版本开始提供）以及 Node 24+。

## 它不做什么

- 会话持久化没有提供删除 API，所以文件移动是插件 Host 半边做的带外操作。移动目录不会改写会话索引；恢复后的会话会从空日志开始，直到后端重新落盘。
- 只有会话自己的存储目录会被移动。工作区归属、归档集合、该会话产出的交付物都留在原处。
- 只有通过本插件动作删除的会话才会进入回收站；内置的「归档」仍然只是归档。
- 只有存储目录还在的会话才能恢复；文件被别处删掉的条目会显示在列表里，但无法恢复。
- 回收站本身没有后台清扫 —— 过期由保留期负责，而过期掉的条目会先落到系统废纸篓。

## 实现结构

一个包，两个半边：

- `index.js` —— Host 半边，负责回收站目录、记录、保留期，以及 `/api/session-trash/` 下的几条精确 Fetch 路由。
- `client.js` —— 浏览器半边，通过共享的 `contextMenus` 服务和框架槽位提供右键菜单项与回收站面板。

这些路由走的是官方 `ctx.connection.fetch.register` 通道，因此自带宿主的 peer 校验：非 owner 页面拿到的是 403，而不是直接调通接口。
